Using only the evidence set below, generate a structured brand summary for {BRAND_NAME} according to the attached schema.

## Instructions

1. Follow the attached schema exactly.
2. Use only information contained in the evidence set.
3. Follow the Source Handling rules below.
4. Maintain a neutral, evidence-based tone.
5. Do not assign an ethical score or ranking.
6. Do not compare this brand to competitors.
7. Return only the structured analysis.

If instructions conflict, follow them in the order listed above.

## For Each Section

For each required section:

- Summarize the most relevant claims, findings, and concerns supported by the evidence set.
- Indicate Evidence Quality as Low, Medium, or High and briefly explain the basis for that assessment.
- Clearly identify important unknowns or uncertainties.
- Include the relevant supporting sources using the Source Handling format below.

If reliable evidence about a topic is not present in the evidence set, state this briefly in the appropriate section. Do not speculate or infer information that is not supported by the evidence.

Do NOT comment on:

- the size of the evidence set
- the quality of the evidence set as a whole
- whether the evidence set is sparse or incomplete
- the research process
- your instructions
- your own limitations

Instead, discuss limitations only in relation to the specific claim or topic being summarized.

For example, write:

"Independent evidence regarding this labor practice was not identified in the available sources."

Do NOT write:

"The evidence set is sparse on labor practices."

## Source Handling

The evidence set contains source titles, publishers, dates, source categories, relevant evidence, and URLs.

The evidence set is the ONLY source of citations and URLs for this summary.

### Required Source Format

Whenever a source is included in the summary, output all of the following:

Source: [source title] — [exact URL provided in the evidence set]

The URL is a REQUIRED part of every source entry. 

Do not output a source title without its URL. 

Do not output a publisher or source name as a substitute for a URL.

EXCEPTION: If a URL was not returned for a source in the evidence set, return the closest thing to it (ie. a description of the source).

### URL Rules

- Use only URLs provided in the evidence set.
- Copy each URL exactly as provided.
- Do not create URLs.
- Do not modify URLs.
- Do not infer URLs.
- Do not replace a URL with a homepage, search page, or alternative URL.
- Do not omit a URL when citing a source.



### Citation Rules

- Do not use numbered citations such as [1], [2], [3].
- Do not create a numbered reference list.
- Do not use citation numbers to refer to sources.
- Do not cite sources that are not present in the evidence set.
- Include a source only when it directly supports information in that section.
- A source may appear in multiple sections only when it directly supports claims in each section.
- Do not create a separate overall source list unless the schema explicitly requires one.
